# LoginApp

Aplicación Android desarrollada como parte de la Actividad 1 de la materia Desarrollo de Aplicaciones Móviles.

La aplicación cuenta con una pantalla de inicio de sesión y una pantalla de registro, permitiendo navegar entre ambas interfaces.

## Funciones

- Pantalla de inicio de sesión.
- Pantalla de registro.
- Campo de nombre de usuario.
- Campo de contraseña.
- Campo de nombre completo en el registro.
- Navegación entre ambas pantallas.
- Interfaz desarrollada con Jetpack Compose.

En esta primera versión no se almacenan usuarios ni se realiza una autenticación real.

## Tecnologías utilizadas

- Android Studio
- Kotlin
- Jetpack Compose
- Android Emulator
- Git
- GitHub

## Instrucciones para ejecutar el proyecto

1. Clonar o descargar el repositorio.
2. Abrir el proyecto utilizando Android Studio.
3. Esperar a que Gradle termine de sincronizar los archivos.
4. Seleccionar un dispositivo virtual Android o conectar un dispositivo físico.
5. Ejecutar la aplicación utilizando el botón Run.
6. Esperar a que la aplicación se abra en el dispositivo seleccionado.

## Requisitos

- Android Studio.
- SDK de Android configurado.
- Dispositivo Android o emulador.
- API 24 o superior.
